## 📖 Project Description

The Customer Churn Prediction System is an AI-powered machine learning web application built using Streamlit.

It predicts whether a customer will churn or stay based on customer behavior data and provides real-time probability output.

It also includes a dashboard for business insights and analytics.

---

## 🎯 Objective

- Analyze customer behavior patterns  
- Predict customer churn using machine learning  
- Improve customer retention strategies  
- Provide interactive dashboard and analytics  

---

## 🧠 Machine Learning Model

- Algorithm: Logistic Regression (Best Model)
- Accuracy: ~81.69%
- Preprocessing: Label Encoding, Data Cleaning
- Libraries: Scikit-learn, Pandas, Joblib
